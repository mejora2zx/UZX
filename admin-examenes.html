Importar calificaciones del Control Maestro (Excel)

Sube tu Excel del Control Maestro para cargar a la plataforma las calificaciones y fechas que ya tenías. Cada curso del Excel se guarda como resultados de un examen. Si la plataforma ya tiene esa calificación (misma persona, mismo examen y mismo día), se omite para no duplicarla. Solo se usan nómina, nombre, departamento, fecha y calificación; el resto de las columnas del Excel (CURP, fecha de alta, etc.) no se importa.
